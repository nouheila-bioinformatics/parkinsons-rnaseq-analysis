# Parkinson's Disease RNA-seq Analysis

## Project Overview
This academic project analyzes RNA-seq data from human post-mortem brain tissue to investigate gene expression differences between Parkinson's disease patients and healthy controls.

## Objectives
- Identify differentially expressed genes.
- Explore biological processes associated with Parkinson's disease.
- Perform functional enrichment and pathway analysis.
- Interpret molecular changes related to the disease.

## Tools and Technologies
- R and RGui
- edgeR
- DESeq2
- Python
- Galaxy
- FastQC
- MultiQC
- Trimmomatic
- HISAT2
- featureCounts
- HTSeq
- clusterProfiler

## Analysis Workflow
1. RNA-seq quality control.
2. Data preprocessing.
3. Read alignment and gene quantification.
4. Differential gene expression analysis.
5. Gene Ontology (GO) enrichment.
6. KEGG pathway analysis.
7. Gene Set Enrichment Analysis (GSEA).

## Preliminary Findings
The analysis highlighted mitochondrial energy-related biological processes.

The KEGG GSEA results did not identify statistically significant pathways after multiple-testing correction (adjusted p-value < 0.05).
